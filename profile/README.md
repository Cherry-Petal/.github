## 🧸 Sobre a loja

A **Cherry Petal Store** é uma loja de importação de produtos japoneses. Trabalhamos com
itens originais trazidos direto do Japão, tanto em **pronta entrega** quanto **sob encomenda**,
para quem quer aquele colecionável específico que não se acha por aqui.

Cada pedido é acompanhado de perto, do orçamento até a entrega. 🍒
